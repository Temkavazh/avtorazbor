# Авторазбор обращений

Интерактивный пример сценария автоматизации: ИИ разбирает обращения клиентов из почты, мессенджеров, с сайта, маркетплейса или из звонка, заводит сделку в Битрикс24 или amoCRM и готовит ответ. Простые случаи закрываются сами, спорные уходят человеку.

Открыть: https://diid-one.github.io/avtorazbor/

Три отрасли на выбор (интернет-магазин, B2B-поставки, сервисная компания), по пять обращений в каждой. Данные тестовые.

Связка в реальной работе: n8n → OpenAI → Битрикс24 / amoCRM. Страница — один HTML-файл без библиотек.
